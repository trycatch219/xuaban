# 本地模型与联网搜索（0.4.0）

## 本地模型

插件只连接已经运行的模型服务，不安装推理软件、不下载模型、不启动后台推理进程。

### Ollama

在本机安装并运行 Ollama，并自行准备模型。在扩展设置中点击“Ollama 本机预设”：

- 协议：Ollama 原生接口。
- 基础地址：`http://127.0.0.1:11434`，不要附加 `/api` 或 `/api/chat`。
- API Key：本机无鉴权服务留空；有反向代理鉴权时按实际配置填写。
- 点击“读取文本模型列表”，选择已安装模型，再测试文本连接。

插件通过 `/api/tags` 获取列表，通过 `/api/chat` 发送消息，支持 NDJSON 流。列表不证明模型支持图像，视觉能力需另行使用红色方块测试。对话请求附带实际 PNG 的 base64 数据，不能让纯文本模型通过配置名变成视觉模型。

### LM Studio / 其他兼容服务

在 LM Studio 中启动本地 API 服务。点击“LM Studio 本机预设”，默认填入 `http://127.0.0.1:1234/v1`；若修改了端口请按实际值填写。模型列表使用 `/models`，聊天使用 `/chat/completions`。

其他本地服务可选“OpenAI 兼容接口”，填写对应基础地址。不同服务的兼容程度需要实测。

### 独立视觉连接

开启“视觉模型使用独立服务地址与 Key”，分别填写视觉协议、基础地址、Key 和模型。可以组合本地文本模型与在线视觉模型，或两者全部本地。独立开关关闭时沿用文本连接配置，只切换视觉模型名称。

整个请求包含历史图片时也会使用视觉连接。切换到另一服务地址时界面会提示，避免用户误以为数据仍发往原服务。旧版的单一连接与 API Key 可以直接读取，首次保存后写入分组凭据存储。

### 本地连接失败

- 确认模型服务已经启动、端口和模型名称正确。
- 本机 HTTP 只允许 localhost 与 127.0.0.1；局域网 HTTP 地址暂不支持。
- 连接列表成功仍需做聊天测试；首次加载模型可能慢于连接列表。
- 403 可能是服务端 Origin / 鉴权配置问题。按服务的官方文档检查，优先仅允许实际扩展来源，不建议开放任意来源。
- 浏览器或系统的本地网络权限提示需要用户正常授权；插件不会修改安全策略。
- 本地模型是否真正离线还取决于服务和所选模型本身；不要将云端转发模型当作本地推理。

## 联网搜索

首版支持 Tavily Search 协议，不内置免费搜索额度。可以使用官方请求地址或兼容同一请求和响应格式的代理，不支持直接填写普通搜索网站首页。

设置搜索请求地址 `https://api.tavily.com/search`，填写独立搜索 API Key。该地址是完整请求地址，与模型“基础地址”不同。可选限定域名（逗号分隔）和最近一天/周/月/年的时间范围。填写域名后仅搜索这些域名，适合查官方技术文档。

### 操作

1. 输入问题并开启“联网搜索”，确认或修改搜索词。默认以问题填充，不自动发送选区、图片或整页正文给搜索服务。
2. 点击“搜索并预览”；搜索服务将收到搜索词及域名/时间限制，可能计费。
3. 检查结果。显示标题、来源域名、正文摘录或搜索摘要、发布时间（若提供）与检索时间。
4. 可以取消不需要的来源。点击“确认发送”后，才将选中的资料与对话送到模型。
5. 回答沿用“来源 N”引用机制；网络来源可查看摘录并打开原网页，不使用当前教程的段落高亮功能。

也可以直接点击发送：若没有对应搜索预览，先搜索并停在预览阶段，不立刻调用模型。与网页模式同时开启时，两类资料都需预览，可能需要多次点击完成准备和确认。

### 读取范围与失败行为

请求最多五条结果，并让服务返回正文。每条摘录最多约 3,500 字符，总计约 12,000 字符。没有正文时使用搜索摘要，并在界面标明；插件不伪装为已经读取完整原文。

搜索服务不一定返回发布时间，未提供时明确显示；检索时间不是发布时间。最近时间过滤不能保证所有结果都是最新或正确，回答应核对版本与来源。

搜索失败、超时或没有结果时不调用模型。用户可以调整后重试，或者明确关闭联网搜索再回答。取消所有来源同样阻止发送。编辑问题、修改搜索词或设置后，旧预览失效。

## 数据、Key 与费用

搜索和推理是两个独立请求。本地推理结合外部搜索时，搜索词仍会发送到外部搜索服务；结果会发送给选择的模型。网页图文是否发送，仍由网页开关与确认选择控制。

三个 Key（文本、独立视觉、搜索）默认存于浏览器会话中，勾选“记住”后写入本地，未加密、不同步。不需要提交任何 Key 到 GitHub。学习记录可包含已经发送的搜索词、结果摘录、URL 和时间，并可导出。
