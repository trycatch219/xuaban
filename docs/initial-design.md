# 学伴：浏览器学习问答插件设计方案

## 已确认范围

桌面浏览器优先。右侧面板展示解答并支持连续追问；第一版支持文字、图片、视频截图；用户填写 API Key 并选择模型服务商。音频和视频片段放在后续版本。暂定名称“学伴”，浅色界面、靛蓝强调色。

## 核心交互

1. 用户点击插件图标，在当前页面启用工具。选中文字出现轻量工具条，提供“解释一下”“举个例子”“提问”，右键菜单作为备用入口。
2. 图片通过右键“用学伴提问”选取；读取失败时可以框选屏幕区域。视频支持用户暂停后截取可见画面，并在能够读取时记录播放时间。
3. 右侧面板展示素材卡片，包含文字摘录或图片预览、网页标题、来源链接、可获得的视频时间。用户可删除附件、裁剪截图、修改问题。
4. 点击发送后流式显示回答，支持停止、重试、复制和连续追问。快捷提示包括“解释一下”“举个例子”“一步步讲解”。
5. 新素材默认作为新问题素材；用户可明确选择“加入当前对话”。切换标签页时保留原对话，提示其来源，并提供“开始本页对话”。

默认仅发送问题、选中素材和本轮对话所需历史。网页来源用于定位，不自动上传整页；添加相邻段落需要用户开启并预览。模型解答与网页原文分开展示，不生成虚假的来源引用。

## 前端界面

### 右侧问答面板

顶部为名称、新对话、历史和设置入口；中部为素材卡片及消息流；底部固定输入框、添加素材、发送/停止按钮。宽度约 380–440px，实际调整能力取决于浏览器。支持 Markdown、代码块、数学公式和图片缩略图。

### 截图选择层

显示遮罩、选择框、取消和确认按钮，支持 Escape 退出。截取前隐藏插件覆盖层；只裁剪并提交选中区域，完整截图仅用于本地裁剪。截图预览提供重新框选、裁剪和删除。

### 设置与学习记录

设置包含服务商、API 地址、API Key、文本模型、视觉模型、连接测试和保存。连接测试区分鉴权、文本请求和图片能力，提示测试请求可能产生少量费用。模型能力未确认时标记“未验证”。学习记录本地保存，可关闭、搜索、删除或导出 Markdown。

### 必须设计的状态

未配置模型、未选择素材、发送中、回答中、完成、停止、网络错误、鉴权失败、额度不足、模型不支持图片、截图失败及受限页面。失败时保留问题草稿，避免重复发送；服务切换前提示原有对话上下文将发送到新的服务商。

## 技术方案

建议 TypeScript + React + Vite，使用 WebExtensions 架构和 Manifest V3 的 Chromium 构建。浏览器能力通过适配层封装，分别生成 Chromium、Firefox 和 Safari 安装包。

- 内容脚本：读取选区、显示工具条、定位图片与视频、管理框选覆盖层。使用 Shadow DOM 隔离样式。
- 侧栏：管理素材、对话、流式回答及模型设置；有权限的扩展上下文负责发起 API 请求。
- 后台：管理权限、浏览器消息和捕获动作。不依赖后台永久驻留来维持聊天状态。
- 模型适配层：统一文本和图像消息、流式事件、取消和错误；按实际协议实现服务商适配，不能仅更改 API 地址就认定兼容。
- 存储：IndexedDB 保存对话与素材，扩展存储保存普通设置。Key 默认保留于会话内存；长期记住须用户开启，且明确浏览器本地存储不是安全保险库。Key 不注入网页、不写日志、不同步。

默认以 activeTab 等按需权限启用当前页面；自动划词工具条需要用户为对应网站授予持续访问权限。模型服务域名按需授权，避免默认申请全部网站访问权。

网页内容按不可信素材处理；第一版仅做问答，不让模型调用网页操作工具。回答 Markdown 清洗并禁止原始 HTML 执行。

## 浏览器与交付

Chrome 和 Edge 使用 sidePanel；Firefox 使用 sidebar_action/sidebarAction。其他 Chromium 浏览器须检测接口，缺少原生侧栏时使用网页内右侧面板，并实际测试。Safari 使用独立打包流程，侧栏交互按实际支持实现，必要时使用网页内面板。

开发阶段提供可加载目录或各浏览器测试包；正式分发按商店要求打包和签名。不存在一个压缩包直接安装到所有主流浏览器的保证。

## 能力边界

跨域图片或视频像素读取可能被浏览器限制，优先以用户触发的可见区域截图备用。DRM 视频可能截图黑屏，不承诺绕过保护。浏览器内部页、扩展商店页和部分 PDF 阅读器无法执行普通内容脚本。跨域 iframe 按权限适配，无法读取时提供框选截图。纯文本模型只能回答文字素材；图片问题需要视觉模型。

## 迭代顺序与验收

先完成 Chrome/Edge 的文字选择、素材预览、API 设置和流式追问闭环；再加入图片及视频截图、记录管理；随后适配 Firefox 和 Safari。

验收重点为：长文及代码选区、不同缩放比例下的截图裁剪、跨域图片和嵌入视频、跨标签页上下文隔离、取消请求和失败重试、模型图像能力差异、Key 不进入网页、浏览器安装及侧栏行为。

后续音频增加用户触发的片段录制、转写预览和时间范围；视频片段增加字幕与关键帧，不能把单帧截图视为理解整段视频。
