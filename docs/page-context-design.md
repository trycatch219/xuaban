# 学伴 0.2.0：结合当前网页

## 产品交互

“结合当前网页”默认关闭。用户开启后输入问题，第一次点击“检索并预览”仅执行本地正文提取和检索。预览列出本次片段，可展开全文和取消勾选；第二次点击“确认发送”才请求模型。关闭开关会停止发送已检索的网页片段，原有提问、回答和手动选中素材仍可作为对话上下文。

回答显示可点击的“来源 N”。点击查看原文后，可定位并高亮网页对应内容。模型未引用的片段也能在用户消息下的“已发送网页参考”中查看。复制保持 Markdown 原文；记录导出包含来源和引用全文。

## 索引与检索

优先选择 article/main 等正文容器，按标题、段落、代码、表格和图注抽取；过滤导航、表单、隐藏内容、已识别广告和评论区。片段保留层级标题与可定位标记。正文较少时整体使用；长正文根据问题、选区与上一轮问题进行本地关键词打分，变量名加权并补充相邻片段。

标题与代码标识符加权，提供概率/对数/累加等少量概念扩展；这是可审查的基础检索，并非覆盖所有语义的搜索引擎。每轮约 14,000 字符预算，正文提取最多 200 片段／240,000 字符。代码和表格在 5,000 字符以内保持整块；超长块按行或字符分片。长页总结按位置抽样，并提示未覆盖全文。

## 来源与状态

对话绑定原页面 URL；改变网页需重新开对话，避免悄然混入其他网页。确认发送前重新检查正文签名，内容改变则重新生成预览。草稿变化、新素材或恢复其他对话使旧预览失效。

无正文、受限页面、无匹配片段、全部取消、源页面关闭、原文改变都有明确状态。无匹配时不偷偷使用无关正文，用户可补充关键词、选择素材或关闭网页模式。

## 数据与权限

仍使用 activeTab 按需读取，不新增所有网页常驻权限。完整索引在侧栏本地临时使用，不上传整页索引；所选片段经用户确认后发送至其模型服务。已发送引用可随用户开启的本地记录保存。模型消息将网页资料标为不可信引用，不提供网页操作工具。

编号有效性由插件校验，真实依据与论证正确性仍需用户核对。原文中的标题、段落、代码和图注可读取，未提供的字幕或视频动作不可视为已理解。

## 实现与验证

context-page.js：正文读取与定位。context.js：本地检索、预算、提示词及来源编号。panel.js：开关、预览、确认发送、状态和历史引用。context.css：引用预览与来源弹窗。

自动化验证覆盖正文过滤、代码表格及公式提取、跨段检索、正文变化、预算、无匹配、来源定位及编号校验；侧栏流程验证第一次预览不调用模型、变化后需重新预览、全部取消不发送、确认后发送、草稿变化使预览失效及跨网页隔离。浏览器真实权限和实际模型回答仍需用户在 Edge 中验证。
