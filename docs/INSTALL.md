# 学伴浏览器扩展 0.3.0

源码仓库根目录的 README.md 包含完整功能、开发、隐私及排障说明。

## 安装与配置

1. Edge 打开 edge://extensions，Chrome 打开 chrome://extensions。
2. 开启开发者模式，点击加载已解压扩展，选择直接包含 manifest.json 的扩展目录。
3. 在普通教程网页点击工具栏中的学伴图标。
4. 进入设置，按服务方实际协议填写 API 基础地址、Key、文本模型和视觉模型。
5. 分别测试文本连接和红色方块图片识别，再保存。

如果安装的是 Firefox 构建，请使用 about:debugging 临时加载对应目录的 manifest.json。该构建未签名，正式分发需另行审核与验证。

## 使用

划选文字或框选截图，检查素材后提问。开启“结合当前网页”后，先检索和预览文字、图片，再确认发送。每轮最多选择三张网页图片；图片读取失败可授权原图域名或截图。含图片请求自动使用视觉模型。

复制保留 Markdown/LaTeX 源文；侧栏显示排版结果。记录可在本地搜索、恢复、删除并导出 Markdown。图片像素当前不随 Markdown 另行导出。

## 更新与数据

保留已加载目录路径，关闭侧栏，在扩展管理页重新加载。不要为更新直接卸载扩展；重要记录可先导出。

Key 默认保存在浏览器会话中，勾选记住后存于本地，未加密。模型请求直接发送至用户配置的服务；图文素材可能含私人信息，发送前请检查。完整说明见随分发包提供的 PRIVACY.md，或源码仓库根目录同名文件。

## 当前边界

未实现 Safari、音频片段或视频字幕读取；部分内部页、嵌入文档和跨域媒体受限。正文和图片推荐采用基础提取与关键词检索，需用户核对。浏览器构建与自动化测试不代表所有实际网站和模型服务已验证。
