# 学伴 0.3.0：图文网页上下文

## 界面与操作

保留“结合当前网页”开关，检索后同一引用预览包含文字与“选择网页图片”。图像卡片展示推荐标识、图注、尺寸、本地预览、发送勾选及定位截图入口。每轮最多三张，用户可以取消推荐图后补选其他候选。

推荐图可直接读取时自动载入；跨域受限显示失败状态，提供明确的域名授权按钮和截图备用路径。只发送有有效 PNG 预览且勾选的图，确认前不调用模型。找不到相关图片时仍可展开候选补选，不将装饰图一律提交。

## 实现流程

正文提取同步收集主文档正文里的 img：currentSrc、替代文字、图注、附近正文、标题、尺寸、可见区域状态和定位标记。过滤小图、隐藏图、正文外图片并去重；最多四十张候选。相似性基于文字与当前问题，不对全页图片先调用模型分类。

先在内容脚本中读取已加载图片并通过 Canvas 压缩成 PNG；遇到跨域限制，只有已获域名权限或用户明确授权后才从扩展读取原图。下载不带 Cookie、不跟随重定向，最大 8 MB；优先缩放最长边 1600px，每张限制约 1.5 MB。读取失败可以定位后截图。图片预览使用本地数据，不在侧栏直接加载外部网址。

确认时再次检查页面正文及图片元数据签名，发生变化则重新预览。文字和图片分配独立来源编号；消息中在图片像素前标明对应编号。只要请求中有图片，就使用视觉模型。两种模型协议沿用现有图片适配。

## 边界

支持正文已加载的 img，不覆盖 CSS 背景图、Canvas 绘图、SVG 内嵌图形、跨域 iframe 或未加载的图片。定位截图可作为备用；本版未新增单独裁剪编辑器。像素变化但 URL 与尺寸均不变的动态图片可能无法通过元数据签名识别。压缩会降低细小文字清晰度，用户可改截局部。

不会自动把整页图片传给模型，不自动授予跨域访问权限。已发送图像可随用户启用的学习记录本地保存；导出 Markdown 提供文字来源，图像像素保存在浏览器记录中。

## 验证

自动化验证包含图片候选过滤、排序、三图预算、补选替换、PNG 消息组装、视觉模型路由、跨域失败与显式授权、原图压缩及已有文字/公式回归。实际网站权限、CORS、防盗链及真实视觉模型效果仍需在 Edge 中验证。
