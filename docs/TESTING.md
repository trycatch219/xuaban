# 验证与手动验收

## 自动化

```bash
npm ci
npm run check
npm test
npm run package
```

八组测试覆盖：在线模型协议与流式分块；Markdown/LaTeX 和 HTML 清洗；正文过滤、检索与来源；侧栏本地预览到确认发送；图片选择与视觉路由；图片跨域失败与压缩；Ollama 原生协议、模型列表、配置迁移与搜索请求；联网预览到本地推理的侧栏流程。

jsdom 与模拟浏览器接口不能证明真实权限提示、Canvas 跨域规则、截图画面或模型识别质量正确。这些部分需手动验证。

## 浏览器验收清单

- [ ] 在 Edge 加载 dist/chromium，侧栏、设置与右键入口可用。
- [ ] 在 Chrome 重复核心流程；在 Firefox 使用 dist/firefox 单独验证。
- [ ] 真实 Key 只填写在本机设置中，文本连接和红色方块测试可用。
- [ ] 刷新网页后重新点击插件图标，文字选择能正常启用。
- [ ] 长段落、代码、表格、公式可以显示，复制保留原文。
- [ ] 不启用网页模式时不读取并发送全页正文。
- [ ] 网页模式第一次点击只产生本地预览；确认后才调用模型。
- [ ] 取消引用、编辑问题、改变网页后，预览与实际请求一致。
- [ ] 切换到其他网页不自动混入新页内容。
- [ ] 推荐图、非推荐图补选、取消与三图上限符合预期。
- [ ] 跨域图片无权限时不自动申请；用户授权后仅访问对应域名。
- [ ] 防盗链、登录图、超大图、加载失败提供截图入口。
- [ ] 确认发送确实包含图像像素，使用视觉模型且能解释真实图片。
- [ ] 来源可以查看原文、图片并定位；原文变化时提示失败而不随意定位。
- [ ] 截图在缩放、高 DPI 和视频暂停画面下裁剪正确。
- [ ] 停止、超时、401、429、无模型权限等情况保留可恢复信息。
- [ ] 关闭记录保存、删除、清除和导出符合界面说明。
- [ ] 保留安装路径重新加载后，设置及已有记录仍可访问。
- [ ] 0.3.0 单一模型配置和 Key 可以读取；保存迁移后不遗留旧 Key。
- [ ] Ollama 无 Key 时可列出已安装模型，真实聊天和图片请求正常。
- [ ] LM Studio 启动 API 服务后列表、聊天和流式响应正常。
- [ ] 文本与独立视觉使用不同地址和 Key，实际请求不混用凭据。
- [ ] 联网默认关闭，搜索词可修改且不自动带上网页素材。
- [ ] 搜索成功后先停在来源预览；全部取消时不调用模型。
- [ ] 搜索失败不调用模型，保留问题并可关闭联网后继续。
- [ ] 外部搜索加本地模型时，来源链接及日期说明清晰。

报告结果应写明浏览器、系统、插件版本和测试网站类型。不要把测试替身成功写成真实模型或所有浏览器验证成功。
